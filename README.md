# 🛠️ MAssistant - Issue Tracker

Welcome to the official issue tracker for **MAssistant**.
This is the place to report bugs, suggest new features, or provide feedback.

📥 **[Download MAssistant on Modrinth](https://modrinth.com/project/massistant)**

---

## 🛑 Before Posting
1.  **Check** that you are using the latest version of the plugin.
2.  **Search** the [existing issues](https://github.com/Martinou2x/Issues-MAssistant/issues) to see if your problem has already been reported.
3.  Please be respectful and provide as much detail as possible.

## 🐛 How to Report a Bug
Go to the **Issues** tab and click **New Issue**. Select "Bug Report" and fill out the form.
* Be specific about what happened.
* Include console logs if there are errors.

## 💡 Have an Idea?
We love suggestions! Use the "Feature Request" template to tell us what you'd like to see in MAssistant.
